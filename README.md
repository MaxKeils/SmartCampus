# SmartCampus

Учебный Android-прототип для лабораторной №7 по DevOps. В прототипе есть расписание на день и неделю, детали переноса, просмотр сохранённой недели без связи, поиск аудитории и учебный маршрут. Экран уведомлений показывает переносы из учебного расписания.

Приложение использует синтетическое расписание. Переключатель «Имитировать отсутствие связи» имитирует недоступность источника. Последняя успешная загрузка хранится на устройстве и доступна после перезапуска. Подключение к университетской системе и веб-кабинет остаются работами продуктового бэклога.

## Архитектура

Используются Kotlin 2.4.21, Jetpack Compose 1.13.0 с Material 3, Hilt 2.60.1 и Jetpack Navigation 3 1.2.2. Экран отправляет события в `CampusViewModel`. Редьюсер обновляет модель состояния, эффекты загрузки обращаются к репозиторию через Hilt, а UI подписывается на `StateFlow`. Navigation 3 хранит типизированный стек. Последнее расписание сериализуется в приватные настройки приложения.

## Запуск и проверка

1. Откройте каталог репозитория в Android Studio. Установите JDK 17, Android SDK Platform 37.2 и SDK Build-Tools 36.0.0.
2. Запустите конфигурацию `app` на устройстве или эмуляторе с Android 9 или новее.
3. Для проверки включите режим «Неделя», найдите перенос, затем включите имитацию отсутствия связи. На экране остаются расписание и время последней успешной загрузки. Отключите имитацию сбоя, откройте вкладку «Карта» и найдите аудиторию 312. В корпусе Б доступны схема первого и третьего этажей и текстовые ориентиры.

Из терминала после настройки Android SDK и `JAVA_HOME`:

```sh
./gradlew testDebugUnitTest assembleDebug lintDebug
```

На Windows используйте `gradlew.bat`. APK находится в `app/build/outputs/apk/debug/app-debug.apk`. На pull request те же проверки запускает [SmartCampus CI](https://github.com/MaxKeils/SmartCampus/actions/workflows/ci.yml).
